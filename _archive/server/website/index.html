01能力速览

十七个页面，收进一个窗口

从最底层的 9008 写入，到最表层的投屏操作 —— 整条链路收在同一个界面里， 不用在几个工具之间来回倒固件。

EDL 900801

救砖级底层写入

绕过系统直接对 UFS / eMMC 写分区，连 Fastboot 都进不去的机器也能拉回来。

FASTBOOT02

槽位识别与快刷

自动识别 A/B 槽位与当前活动槽，boot / dtbo / vbmeta 按槽位写入。

MTK BROM03

联发科刷写通道

BROM 握手与 DA 高速通道，解析 scatter，下载、读回、擦除分区。

GPT / LUN04

按分区勾选即刷

OFP / OPS05

欧加线刷固件

直接解析厂商 OFP / OPS 包，不必先手工转成 rawprogram 再刷。

SCRCPY06

投屏与键鼠接管

内置 scrcpy，刷机前后都能在电脑上直接操作设备、看进度。

03使用流程

四步走完一次刷机

每一步都可以停下来看日志、看进度，出了问题能回到上一步； 不需要刷机时，工具组的七个页面可以单独使用。

01

连接设备

自动检测 ADB / Fastboot / EDL 9008 与联发科 BROM 设备，认出芯片型号，驱动异常时给出明确指引。

02

读取分区表

逐 LUN 解析 GPT，分区按组呈现，可搜索、可勾选 —— 只动你选中的那几个。

03

解析固件

rawprogram / patch XML 与 MTK scatter 全量解析，分段镜像按原始扇区完整刷入。

04

刷写与复位

实时进度与速率反馈，完成后自动重启；全程日志可保存回溯。

公测期间完全免费，全部功能开放，不需要付费。公测结束转入正式版后会启用会员授权，价格会提前在官网与控制台公示；公测期间注册的账号会保留。工具收费只会用于维护工具与维护服务器，不会用于其他用途。

不需要。自 2.0.0 起 KunClient 为原生单文件程序，下载后双击即可运行，无需安装 .NET 或其他运行时。

有。下载区提供 7z 压缩包（约 10.6 MB，约为完整包的 1/4），用 7-Zip 或 WinRAR 解压后得到完全相同的 KunClient.exe；两种包内容一致，只是分发形态不同。

分两条芯片线：高通机型走 Fastboot / EDL，常见品牌包括 OPPO、OnePlus、realme、小米、vivo、iQOO、三星等；联发科机型走 MTK BROM 通道。实际能否刷写取决于机型固件与解锁状态。

支持。MTK 页负责设备发现、BROM 握手与 scatter 解析，已打通 DA 高速通道，可直接下载、读回与擦除分区。

EDL（Emergency Download）是高通芯片的紧急下载模式，设备管理器中显示为 9008 端口，用于深度刷机与救砖。联发科对应的底层通道是 BROM。

它是一个 ADB / Fastboot 指令台：常用指令有可视化入口，也可直接输入原始命令，输出原样回显，适合排查设备状态或执行工具里没做成按钮的操作。

把常用的 USB / ADB / Fastboot / 联发科驱动集中在一处下载安装，避免装机时到处找驱动；驱动包由服务器统一分发，打开即可取用。

在控制台首页即可注册，注册需要填写邮箱并输入邮件验证码；登录邮件通知可在注册时自行选择是否开启。
