本次更新（2.0.7 功能补充，2026-10-30）：

【一、刷机记录与导出】

· 新增「刷机记录」：每次写入 / 擦除 / 回读 / XML 刷机 / 整盘擦除 / GPT 读写 / 恢复出厂 /
  基带备份完成后自动记一条（时间、操作、设备、来源包、分区摘要、成败、耗时、完整消息），
  只留最近 500 条。EDL 页「高级功能 ▾ → 记录与导出 → 刷机记录」可查看、导出 CSV / TXT、清空。
  不连设备也能开——设备刷坏了、工具刚启动时，正是最需要回看「上次到底做了什么」的时候。
· 分区表支持右键菜单：复制分区名、复制整行、导出 CSV / TXT。
  连设备读出的 GPT 导出 7 列（含 LUN / 起始扇区 / 扇区数），载入 rawprogram XML 的包清单导出 4 列。
· EDL 日志头新增「导出」按钮：把当前日志存成 .txt，不再需要手动框选两千行复制。
· 设置页「诊断与日志」新增「导出诊断包」：把最近 5 天会话日志 + 版本 / 系统信息打成一个 zip，
  打完自动在资源管理器里选中该文件，直接拖进聊天窗就能发给开发者。


【二、iOS 玩法六件套】

设置页新增「iOS 玩法」卡片，六项开关全部当场生效，不用重启：

· 辅助触控悬浮球：屏幕边上一个可拖动的小白点，点开是主屏 / 控制中心 / 快捷指令 /
  刷机记录 / 通知中心 / 待机 / 专注七个快捷入口。位置会记住。
· 通知中心：顶栏铃铛（有未读时亮红点），点开是一份通知历史，最多 100 条、按
  信息 / 成功 / 警告 / 错误四档着色。原来那些一闪就没的横幅，现在都留了一份。
· 待机模式：无操作一段时间后整屏大时钟 + 日期 + 设备读数，点一下任意处就回来。
  自动进入的秒数可在设置里调，设成「从不自动」也可以手动打开。
· 专注模式「刷机模式」：一键把界面收窄到刷机与设备两页，悬浮球收起、横幅静音。
  状态会记住，重开还是专注态。
· 主屏小组件：主屏顶部三块玻璃卡——设备（型号 / 链路）、最近刷机（自动取最新一条记录）、
  时钟（日期 + 星期）。
· 快捷指令：把「连接设备 → 读 GPT → 备份」这种每天重复的动作串成一条，一键跑完。
  支持连接 / 读 GPT / 备份全部 / XML 刷机 / 校验摘要 / 重启 / 等待七种动作。
  配置是一行一条的文本，存在设置目录里，可以直接手改。

  快捷指令的两条硬规矩：
  · 失败即中止——第一个失败的步骤处立刻停下，「已完成 N 步」就是真实的安全进度。
    刷机流程里「读 GPT 失败还继续刷」是灾难。
  · 不碰设备——页面只把动作转交给对应设备页，由你在那里确认。只有「校验摘要」
    和「等待」是本地直接执行的。


【三、修复】

· 修掉「iOS 玩法」卡片建好了却没加进设置页布局、界面上根本找不到的问题
· 修掉主屏小组件、快捷指令页两个开关要重启才生效的问题（设置页写着「当场生效」）
· 修掉「关掉快捷指令 → 进一次专注模式 → 退出」后快捷指令图标自己冒回主屏的问题
· 修掉从悬浮球切换专注模式后状态不落盘、重开程序专注模式自己没了的问题


【四、其他】

· Firehose 启动检查不再固定睡 700ms：改成短超时递进试探，快固件第一次就过，
  慢固件也不会因为「只等了一次」就判失败。连接设备更快，且更不容易误报失败。
· 以上全部为纯本地功能，不依赖任何服务器。
